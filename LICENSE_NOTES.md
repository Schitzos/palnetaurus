# License Notes — Planetaurus

## Allowed Sources
- CC0 assets (no attribution required)
- CC-BY assets (attribution required — add to ATTRIBUTION.md)
- Self-created assets
- Paid assets with valid license
- AI-generated assets with clear usage rights

## Prohibited Sources
- Pokémon / Nintendo assets
- Jurassic Park / Jurassic World ripped assets
- Random Google Images without license
- Assets with unclear or restrictive licenses
- Paid assets without purchased license

## Rules
1. Every imported asset MUST have an entry in ATTRIBUTION.md
2. Verify license BEFORE importing
3. Store originals in src/assets_raw/ if processing is needed
4. Final assets go in src/assets/
